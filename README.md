1. Project Title:
Student Performance Analytics System
2. Objective:
Is project ka main maqsad 20 students ka ek sample dataset banakar unke marks, grades, aur attendance ka analysis karna hai, taaki yeh pata chal sake ki kaun se students ko extra improvement ki zarurat hai aur class ka overall performance kaisa hai.
3. Tools & Libraries Used:
Python (Programming Language)
Pandas (Data manipulation aur CSV file handling ke liye)
NumPy (Numerical calculations ke liye)
Google Colab (Coding environment)
4. Key Features Implemented:
20 students ka dataset (Student ID, Name, Department, Marks, Attendance)
Total marks aur Average marks ka calculation
Automatic Grade assignment (A, B, C, D, Fail logic)
Pass/Fail status check
Class Summary (Class Average, Highest Marks, Lowest Marks)
Subject-wise performance analysis
Top 5 performing students ki list identify karna
Analysis result ko student_report.csv file mein save karna
5. Conclusion:
Yeh project successfully complete ho gaya hai. Isse students ke performance ko track karna aur weak students ki help karna asan ho gaya hai.
